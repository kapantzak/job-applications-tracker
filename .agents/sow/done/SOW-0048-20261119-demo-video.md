# SOW-0048 - Short demo video of the main user path

## Status

Status: completed

Sub-state: recorded and validated on 2026-11-19 on branch `Update-docs`; committed with the work once the user approves. GitHub playback of the MP4 link is checked after push (see Followup).

## Requirements

### Purpose

Show new users, in about a minute and a half, what the app does: from uploading a CV, to finding jobs, to Gmail sync.

### User Request

"A short explanatory video for the app. No voice, just short explanation messages on selected points of the video. The video should demonstrate a simple user path. From uploading the CV, to job searching and Gmail sync."

### Acceptance Criteria

- An MP4 under `docs/video/` follows the approved storyboard, with on-screen captions and a visible pointer.
- The README shows a poster image that opens the video.
- `scripts/demo-video/` records it again from a clean state with one command.
- Only invented data appears.

15. Storyboard approved (about 75-90 s, 1440×900, light):
    1. Empty start screen: "Find jobs and track applications. Runs on your machine."
    2. Upload CV: "Start from your CV: PDF, Word or text."
    3. Progress: "Your own agent CLI drafts a profile from it."
    4. Review and create: "Check the draft. Nothing is saved until you create it."
    5. Find jobs → Run page: "Your agent searches the web. Follow along in plain words."

    9. Review page: "Every proposal shows the email as evidence. Nothing changes until you accept." Accept one status change and one new application.
    10. Dashboard: "See where every application stands." End card: `npx job-applications-tracker`.

## Lessons Extracted

- `playwright install` garbage-collects cached browsers that no live Playwright copy links to, across every project on the machine. Any script that installs Playwright browsers must set `PLAYWRIGHT_SKIP_BROWSER_GC=1` (recorded in `AGENTS.md`).
- Playwright's `recordVideo` is too soft for UI text at 1440×900; a DevTools screencast plus ffmpeg is sharper and smaller.
- Watching the frames found problems no test would: captions over the thing they describe, sideways table scroll, UTC-midnight dates.
